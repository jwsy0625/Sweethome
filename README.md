# 🏠 Sweethome - Personal Brand Homepage

> 사랑스럽고 보면 기분이 좋아지는 알록달록한 퍼스널 브랜드 홈페이지

행복한 순간들을 함께하는 따뜻하고 긍정적인 개인 브랜드 웹사이트입니다. 🌈💖

## ✨ 특징

- **현대적인 디자인**: 부드러운 그래디언트와 따뜻한 색상 팔레트
- **반응형 레이아웃**: 모든 기기에서 완벽하게 작동
- **인터랙티브 요소**: 부드러운 애니메이션과 호버 효과
- **접근성**: 모든 사용자를 위한 친화적인 인터페이스

## 🎨 색상 팔레트

- **주요 색상**: 분홍색 (#FF6B9D)
- **보조 색상**: 주황색 (#FFA751)
- **악센트**: 민트색 (#A8E6CF)
- **배경**: 부드러운 패스텔 톤

## 📱 섹션

### 홈 (Hero)
- 인상적인 웰컴 메시지
- 명확한 CTA 버튼

### 소개 (About)
- 4가지 핵심 가치
- 카드형 레이아웃
- 호버 애니메이션

### 포트폴리오 (Portfolio)
- 최근 활동/프로젝트 전시
- 그리드 레이아웃
- 인터랙티브 오버레이

### 연락처 (Contact)
- 소셜 미디어 링크
- 이메일 연락처
- 메시지 옵션

## 🚀 시작하기

### 요구사항
- 최신 웹 브라우저 필요
- 인터넷 연결 필요 (구글 폰트 로드)

### 설치
1. 이 레포지토리를 클론하세요
```bash
git clone https://github.com/jwsy0625/Sweethome.git
```

2. 파일 구조
```
Sweethome/
├── index.html
├── styles.css
├── script.js
└── README.md
```

3. `index.html`을 브라우저에서 열기

## 📝 커스터마이징

### 색상 변경
`styles.css`에서 CSS 변수를 수정하세요:
```css
:root {
    --primary-color: #FF6B9D;
    --secondary-color: #FFA751;
    --accent-color: #A8E6CF;
}
```

### 콘텐츠 수정
`index.html`에서 다음을 변경하세요:
- 제목과 부제목
- 소개 텍스트
- 연락처 정보
- 소셜 미디어 링크

### 포트폴리오 항목
포트폴리오 섹션의 항목을 추가/삭제하려면 `index.html`의 `.portfolio-item` 요소를 수정하세요.
